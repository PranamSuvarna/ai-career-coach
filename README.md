# 🚀 AI Career Coach

An AI-powered Career Guidance & Resume Analysis platform built using FastAPI, Streamlit, NLP, and Machine Learning.

---

# 🌟 Features

✅ AI Career Prediction  
✅ Resume Upload & Analysis (PDF)  
✅ NLP-based Skill Extraction  
✅ AI Career Chatbot  
✅ Resume Scoring System  
✅ Missing Skills Detection  
✅ Career Roadmap Generator  
✅ Interactive Streamlit Dashboard  
✅ FastAPI Backend  
✅ Modern ChatGPT-style UI

# ⚡ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/ai-career-coach.git
```

---

## 2️⃣ Open Project

```bash
cd ai-career-coach
```

---

## 3️⃣ Create Virtual Environment

### Windows

```bash
python -m venv venv
```

Activate:

```bash
venv\Scripts\activate
```

---

# 📦 Install Dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ Run Backend

```bash
cd backend
python -m uvicorn main:app --reload
```

Backend runs at:

```text
http://127.0.0.1:8000
```

---

# ▶️ Run Frontend

Open new terminal:

```bash
cd frontend
streamlit run app.py
```

Frontend runs at:

```text
http://localhost:8501
```
